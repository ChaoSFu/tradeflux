## 结论只有四种，不混用

| 结论 | 含义 |
|------|------|
| 通过 PASS | 条件满足 |
| 拦截 BLOCK | 有明确拦截证据：跌停可信下界 >10、最大空头封死 / 回封 / 创新低、高位跌停 |
| 条件未满足 NOT_MET | 数据齐了、条件没到 |
| 数据不足 INSUFFICIENT | 缺数、过期、覆盖不全——**一律不放行** |

市场五项合起来：有拦截先报拦截，其次条件未满足，再次数据不足；全部通过才是「市场过关」。

## 一、市场过关

1. **跌停家数（硬条件，用户纪律）**：此刻仍封跌停、非 ST、沪深。0–10 继续；11–20「不开新仓」；>20「停手 · 空仓」。
   - 来源：东财跌停池（2026-11-20 实测 58 行、无 ST 无北交所）。按（交易所, 代码）去重，ST / 北交所显式剔除（计数写在覆盖里）。
   - **逐只拿实时行情核**：开盘前跌停池给的是上一交易日名单、`qdate` 却写今天（11-23 09:08 实测 lbt 全是 15:00）。
     核出四种：确认跌停 / 已离开 / 行情过期（日期不对或比此刻早 5 分钟以上）/ 没核上。
   - 下界 = 确认跌停只数；上界 = 下界 + 过期 + 没核上 + 接口自报总数里没拿到的行。
     池子不可信（没拿到、一半以上行情过期、封板时间晚于此刻、接口没给总数）→ 上界未知；这时沪深两市涨跌分布都返回了，
     才拿它（含 ST，是上界）补上界，否则涨跌分布只对照。
   - 真 0：接口给 `tc=0` 的空池（涨跌分布说 >10 家时不认）。
2. **最大空头·近 3 日领跌**：近 3 个**已结算**交易日累计跌幅最深的（库里有日快照的非 ST 沪深票，跟踪范围，不是全市场）。
3. **最大空头·封单最重**：当日首个可信跌停池快照里封单额最大的那只锁定；之后出现比已锁的都重的封单，加进来重新核（最多 5 只）。
   开板离池照样跟踪。锚的状态：已锁定 / 可信快照确认此刻没有封跌停的票 / 待核（还没有可信快照，或存的读不回来）。
   锁定的都止跌了，但这次跌停池不可信 → 数据不足（没法确认没冒出更重的）。
   - 止跌（两项同一套）= 离开跌停价（没碰跌停的看当日低点）后走完 ≥10 分钟、反弹 ≥2%、回落 ≥0.8% 的回踩低点比地板高 ≥1%、
     此刻在回踩低点之上。此刻在跌停上 → 封死 / 回封（拦截）；低点就在最近 3 分钟 → 还在创新低（拦截）。每次刷新从头重算，
     止跌之后回封 / 跌回回踩低点自动撤销。「回踩」取地板之后**最深的那次回落**。
4. **大盘止跌放量**：四大指数分钟价（只用已走完、没过期的分钟），至少两只低点之后 ≥5 分钟没破、离低点反弹 ≥0.3%；
   同期比 = 沪深两市截到同一根走完的 bar 的累计成交额 ÷ 上一交易日同一时刻（按结束时刻对齐），≥1.0 算放量；
   上涨家数占比 <40% 而指数守住反弹 →「权重托举」。
5. **高标负反馈收敛**：上一交易日高标池（近 60 日最高连板 ≥4）里生命周期是连板中 / 刚断板 / 修复中的票。
   已核实的高位跌停 → 先拦截；样本拿到行情 <5 只或 <80% → 数据不足（没法证明高位跌停已清零）；
   中位 >0 且红盘 ≥50%，**行情时间隔 ≥60 秒再看一次、两次都拿到行情的同一批票仍为正且没再走弱**才通过；
   仍为负但比当天最差高 1 个百分点 →「修复中」。

## 二、主线走强

- 候选两个方向：旧主线 = 上一交易日收盘主升雷达里点火 / 主升 / 加速 / 高潮 / 分歧的关注板块（分歧 =「分歧后修复」）；
  上一交易日没有状态时用最近一天的，照实标「回退」。新方向 = 今天涨停 + 触板落在同一关注板块 ≥3 只。
- 重叠概念归并**只影响展示**：今天活跃成分重合 ≥60%（按少的一边算）并成一组，代表板块取活跃只数多、活跃占比高、行业优先的那个。
  广度、分时、带队、跟进、入口都只用代表板块自己的成分。最多评 5 组、显示 3 组。
- 三项证据（同一轮行情）：① 板块低点不晚于上证低点 5 分钟；这一轮（两个低点里早的那个起）板块比上证多涨 ≥1 个百分点；
  ② 回踩过（≥0.5 个百分点）、回踩期间这一轮的相对强度一直 >0、之后收复回落的一半；③ 成分股上涨占比 ≥55%、≥3 只涨 ≥3% 或封板。
- 新方向只有一轮脉冲 →「新方向待确认」。板块分时拿不到或过期 → 成分股同向快照够强就留作「候选：缺分时证据」。

## 三、带队个股

- 候选：代表板块里的昨日人气核心、近 20 日有涨停、今天涨停 / 触板的成员。
- 「什么时候先动」：首次触板时刻；没触板的用分时第一次 +5%。**只比可比的事件**：前排有没触板的、它的 +5% 比带队的触板还早时，
  要取到带队自己的 +5% 时刻才比得了，否则「依据不可比」；带队本身没触板 → 跟进按触板算，依据不可比（最多待验证）。
- 「后来哪几只跟进」：同板块、首次触板晚于它、且在这一轮（板块分时起点）之后；同一分钟分不出先后只标「同向」；<2 只 → 待验证。
- 「回落有没有承接」：炸板后回封 → 有；封住没开过 → 算「此刻封着」，写明没经过回落检验；没封 → 最深一次回落守住涨幅一半。
- 走弱（回落没守住 / 翻绿）的跳过，按它之后的行情评接力者，卡片写「接力」。
- 排序：先动时刻 → 昨日人气核心 → 连板高度 → 近 20 日涨停 → 流通市值小 → 价格低。**不用龙头分**。

## 入口

连续竞价时段 + 市场过关 + 主线确认 + 带队确认 → 「进入买入检查」，带 `code` 和该主线代表板块的 `sector_id`。
首屏的主线、带队股和按钮是同一条（后端 `focus`）。买入检查页读 `sector_id`：必须是正整数、且在这只票的板块里，不是就退回默认板块并提示。

## 买入检查（pretrade_v4）

LIVE 检查（打开和提交评估都是）调 `hard_risk`：跌停家数 + 两项最大空头，跟卡片同一套规则、同一份封单锚。
拦截 → FAIL（BLOCKED）；还没止跌 / 数据不足 / 过期 → 「尚未满足」（WAIT）。从卡片点进去之后市场转差，提交时照样拦。
历史模式不复核这两项（要盘中跌停池和分时，没存），列一行说明。每次检查存下当时的事实（`facts_json`）和规则版本，旧存档不重算。

## 当天要记住的：AppConfig 当日状态

键 `buy_recog_day:YYYY-MM-DD`：封单锚（锁定时刻、依据）、第一次可信快照时刻、高标观测（行情时间、每只的涨幅）。
写的时候重读合并（锁按代码并集、观测按时间并集），并发写冲突重试一次。这不是复盘数据：盘中跟踪照旧不落任何复盘记录。

## 盘后研究

所选交易日：跌停家数（收盘非 ST 日快照）、高标反馈（昨日样本 × 当天收盘）、主升雷达收盘状态（回退的照实标）、成分股首封先后可证；
最大空头两项、大盘止跌放量、板块分时证据、带队承接要盘中观测——没存，一律「盘中无法复核」。不给结论、不给入口。

## 阈值

跌停 10 / 20 是用户纪律；其余（2% / 0.8% / 1% / 5 分钟 / 0.3% / 1.0 / 40% / 60% / 55% / 3 只 / +5%、时效 3 / 10 分钟 / 5 分钟）
都是**工程初始值**，没拿历史回测过，都在 `buy_recognition_rules.py` 顶部。上线后看实战再调，调之前先量。

## 请求预算

不加轮询，跟盘中跟踪同一个刷新节奏。先取跌停池 + 少量行情（跌停池成员、高标样本、锁定标的、近 3 日领跌）把硬条件判出来，
同时发出成分股行情和板块分时（停手 · 空仓就不发）；跌停池 30 秒缓存、分钟 60 秒、行情按只 15 秒（跟盘中跟踪共用、同键并发合并）。
整体最多等 9 秒，没回来的那项这次数据不足。2026-11-23 下午本机实测冷启动 5–10 秒（看东财 / 新浪当时快慢），同一行情时间再刷 0.01 秒。
