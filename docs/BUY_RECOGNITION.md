## 结论只有四种，不混用

| 结论 | 含义 |
|------|------|
| 通过 PASS | 条件满足 |
| 拦截 BLOCK | 有明确拦截证据：跌停 >10、最大空头封死 / 回封 / 创新低、高位跌停 |
| 条件未满足 NOT_MET | 数据齐了、条件没到 |
| 数据不足 INSUFFICIENT | 缺数、过期、覆盖不全——**一律不放行** |

市场四项合起来：有拦截先报拦截，其次条件未满足，再次数据不足；全部通过才是「市场过关」。

## 一、市场过关

1. **跌停家数（硬条件，用户纪律）**：此刻仍封跌停、非 ST、沪深。0–10 继续；11–20「不开新仓」；>20「停手 · 空仓」。
   - 来源：东财跌停池（2026-11-20 实测 58 行、无 ST 无北交所，跟系统跌停名单同范围）。
   - **逐只拿实时行情核**：开盘前跌停池给的是上一交易日名单、`qdate` 却写今天（11-23 09:08 实测 lbt 全是 15:00）。
     行情显示已离开跌停价的不计；一半以上行情是旧交易日 / 封板时间晚于此刻 → 数据不足。
   - 缺页（`tc` 比行数多）、空响应、超时 → 数据不足。真 0 只：接口给 `tc=0` 的空池，且东财涨跌分布不 >10。
   - 有几只没核上行情：计数给区间，区间跨档 → 数据不足。
   - 对照口径：东财涨跌分布（含 ST、北交所，所以一般比跌停池多）。两个数并排显示；跌停池坏了但它都 ≤10 时兜底放行。
2. **最大空头止跌**：锁两类标的逐一核对——
   - 近 3 个已结算交易日累计跌幅最深的（库里有日快照的非 ST 沪深票，**跟踪范围，不是全市场**）；
   - 当日首个可信跌停池快照里封单额最大的；之后出现更重的封单就加进来（最多 3 只）。开板离池后继续跟踪。
   - 止跌 = 离开跌停价（没碰跌停的看当日低点）后走完 ≥10 分钟、反弹 ≥2%、回落 ≥0.8% 的回踩低点比地板高 ≥1%、
     此刻在回踩低点之上。此刻在跌停上 → 封死 / 回封（拦截）；低点就在最近 3 分钟 → 还在创新低（拦截）。
   - 「回踩」取地板之后**最深的那次回落**——回踩完又创新高的照样算回踩过（2026-11-23 测试抓到的坑）。
3. **大盘止跌放量**：四大指数分钟价（只用已走完的分钟），至少两只低点之后 ≥5 分钟没破、离低点反弹 ≥0.3%；
   同期比 = 此刻沪深累计成交额 ÷ 上一交易日同一时刻，**只比已走完的 bar**（正在走的那根今天只有一部分，09:33 实测会把比值压到 0.84），直接显示比较时刻，≥1.0 算放量；
   上涨家数占比 <40% 而指数守住反弹 →「权重托举」，市场继续等。
4. **高标负反馈收敛**：上一交易日高标池（近 60 日最高连板 ≥4）里生命周期是连板中 / 刚断板 / 修复中的票。
   高位有跌停 → 拦截；样本拿到行情 <5 只或 <80% → 数据不足；中位 >0 且红盘 ≥50%，**隔 ≥60 秒再看一次仍为正且没再
   走弱**才通过；仍为负但比当天最差高 1 个百分点 →「修复中」。

## 二、主线走强

- 候选两个方向：旧主线 = 上一交易日收盘主升雷达里点火 / 主升 / 加速 / 高潮 / 分歧的关注板块（分歧 =「分歧后修复」）；
  新方向 = 今天涨停 + 触板落在同一关注板块 ≥3 只。
- 重叠概念归并：今天活跃成分重合 ≥60%（按少的一边算）并成一组，代表板块取活跃只数多、活跃占比高、行业优先的那个。
  最多评 5 组、显示 3 组。
- 三项证据（同一轮行情）：① 板块低点不晚于上证低点 5 分钟、此刻跑赢上证 ≥1 个百分点；② 回踩过（≥0.5 个百分点）、
  回踩期间一直跑赢上证、之后收复回落的一半；③ 成分股上涨占比 ≥55%、≥3 只涨 ≥3% 或封板。
- 新方向只有一轮脉冲（没回踩 / 回踩后没再走强）→「新方向待确认」。板块分时拿不到 → 成分股同向快照够强就留作
  「候选：缺分时证据」。
- 板块分时：东财 push2his trends2（`secid=90.BKxxxx`），60 秒缓存；成分股行情等权，单板块 >800 只不取，一次刷新成分股行情最多 1000 只（活跃只数多的组先用）。

## 三、带队个股

- 候选：组里的昨日人气核心、近 20 日有涨停、今天涨停 / 触板的成员。
- 「什么时候先动」：首封 / 首次触板时刻；没有就用分时第一次 +5%。「回落有没有承接」：封着算有（炸板后回封也算）；
  没封看最深一次回落是否守住涨幅一半。「后来哪几只跟进」：组里首封 / 触板时刻晚于它的。
- 同一分钟分不出先后只标「同向」；之后跟进 <2 只、没分时、先后缺失 →「带队待验证」。
- 排序：先动时刻 → 昨日人气核心 → 连板高度 → 近 20 日涨停 → 流通市值小 → 价格低。**不用龙头分**（自造黑箱分数）。

## 入口

市场过关 + 主线确认 + 带队确认 → 「进入买入检查」，带 `code` 和该主线代表板块的 `sector_id`。
买入检查页读 `sector_id`：必须是正整数、且在这只票的板块里，不是就退回默认板块并提示。

## 当天要记住的两件事在进程内存里

盘中跟踪按设计一行不写库。「首个可信跌停池快照的封单锁定」和「高标反馈上一次观测」只记在服务进程内存：
服务重启从重启后的第一次重新算；早于第一次打开页面就开板离池的票看不到。卡片上照实写。

## 盘后研究

所选交易日：跌停家数（收盘非 ST 日快照）、高标反馈（昨日样本 × 当天收盘）、主升雷达收盘状态、成分股首封先后可证；
最大空头止跌、大盘止跌放量、板块分时证据、带队承接要盘中观测——没存，一律「盘中无法复核」。不给结论、不给入口。

## 阈值

跌停 10 / 20 是用户纪律；其余（2% / 0.8% / 1% / 5 分钟 / 0.3% / 1.0 / 40% / 60% / 55% / 3 只 / +5%）都是**工程初始值**，
没拿历史回测过，都在 `buy_recognition_rules.py` 顶部。上线后看实战再调，调之前先量。
